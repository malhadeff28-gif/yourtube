# How live curation works

`server.js` watches locally stored Codex Desktop user-message events while live mode is enabled. A 12-second debounce coalesces nearby events; the system does not run on a schedule. It processes at most one update at a time, keeps a small in-memory queue, and uses up to three recent user messages from the same chat to interpret follow-ups. Messages that arrive while paused are discarded, and the pause persists through service restarts.

For a relevant event, the service sends a short, best-effort-redacted user-text excerpt and existing generic feed contexts to an ephemeral read-only Codex invocation. Connected apps, plugins and shell tools are disabled. The classifier treats the message as untrusted data and proposes a general public search phrase. A separate Codex invocation receives only that phrase and uses web search to find real video IDs; the service checks IDs using YouTube oEmbed before updating `dist/feed.json`. Search may take a minute or more. Web search sees the derived phrase, and redaction/generalization are imperfect; the README explains the privacy boundary.

`dist/feed.json` stores inferred context and verified video metadata. Edits and saved videos remain in browser-local storage. The service atomically writes validated feed updates and sends a local server event, so an open page updates without reloading. Existing project IDs stay stable when the classifier matches them. If access, inference, search, verification or validation fails, the service reports a status and keeps the prior feed. The app does not read screenshots or browser pages. Chat format, search availability and YouTube availability can change.

The event watcher covers local Codex Desktop session files, not ChatGPT web/mobile chats or remote-only conversations. It starts from the end of existing files, so it does not backfill messages sent while stopped. The optional user-level launch service can run after login. The `Live` control pauses processing persistently, and `scripts/service.py remove` uninstalls the service. A fresh public checkout starts paused.
